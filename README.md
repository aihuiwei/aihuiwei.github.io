# aihuiwei.github.io

Source for [Aihui Wei's academic website](https://aihuiwei.github.io/), built with [Hugo](https://gohugo.io/) and deployed to GitHub Pages by GitHub Actions on every push to `main`.

| Content | File |
|---|---|
| Name, role, links | `hugo.toml` (`[params]`) |
| Homepage text | `content/_index.md` |
| Job market paper | `data/jmp.yaml` |
| Working papers, work in progress | `data/papers.yaml` |
| Presentations | `data/presentations.yaml` |
| Teaching | `data/teaching.yaml` |
| CV | `static/files/Aihui_Wei_CV.pdf` |
| Styles | `static/css/site.css` |

Preview locally with `hugo server`.
